# 个人研究版与 DeepSeek

本次重点是无券商账户的个人研究：注册关注股票 → 更新 SEC → 补齐 EX-99 → 候选提取 → 原文核对 → 机会研究 → Massive 行情更新 → 持续跟踪。真实案例与长期验收按用户要求后置，不把合成测试当成真实效果证明。

## 使用

1. 演示入口 `http://127.0.0.1:8787/#research` 可查看“研究动态”。该库仍是隔离合成数据。
2. 真实个人工作区：`.venv/bin/python -m usoe --port 8788`，访问 `http://127.0.0.1:8788/#today`。不会要求配置 IBKR。
3. 在设置页注册股票、CIK、公司名和板块。在“研究动态 → 个人关注设置与自动提取”中勾选需要关注的股票及事件类型；默认财报/指引优先。取消股票勾选会暂停本研究流程对该股票的 SEC 更新（不删除历史证据，也不影响另行启动的独立任务）。
4. 配置本机 `.env` 后重启服务：

```dotenv
SEC_USER_AGENT=USOpportunityEngine/1.0 contact your-email@example.com
MASSIVE_API_KEY=
MASSIVE_DATA_MODE=historical
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_DAILY_REQUEST_LIMIT=20
```

已有 SEC 联系配置保留，不需重复提供。网页不读取或回显 Key。模型名可以修改；默认值依据本次查阅的 DeepSeek 官方文档。

5. 点“更新研究数据”，或先在设置页同步 SEC。证据中心可以“补齐 EX-99 展品”，再点“DeepSeek 提取候选事实”。支持匹配 EX-99/earnings/press release 文件名的 HTML/文本，每次最多 5 份；PDF、未匹配附件需人工补充，未宣称覆盖全部披露。
6. 在设置页切换 AI Assist。仅有 Key 不会自动发送数据；手动点击提取/解释或在研究偏好中启用自动提取才会调用。
7. 在“研究动态 → 候选事实复核”打开候选草稿，查看原文并修改 JSON。确认指标含义、单位、期间、GAAP 口径和数值后勾选复核，再“验证并纳入研究”。数字与原文不一致、引用不存在、公司/时点不匹配、未知指标、重复指标均阻断。
8. 新研究记录的行情初始明确为待补齐。进入详情点击“同步 Massive 并重新计算”；配置行情 Key 后，研究轮询也会更新。没有行情不会生成虚构价格或声称研究条件满足。

## 状态独立

“研究条件满足”只表示证据、基本面、价格和失效规则等非账户条件通过，不是 READY 交易状态。无账户只影响执行，不影响事件方向研究；原有仓位风控、订单确认和规则重放保留不变。

研究视图会按当前时间重新检查新鲜度。历史/延迟数据不能冒充实时研究价格条件；未满足的条件直接列出。GET 研究视图只读取与计算，不直接调用 AI 或外部数据源；真实工作区打开页面会另行检查并启动必要的后台同步。若已开启 AI Assist 和自动提取且有可用凭据、额度，后台更新可能调用 DeepSeek。

## DeepSeek 边界

- 直接调用官方 HTTPS `/chat/completions`，JSON object 输出，不依赖外部 SDK。
- 提取只发送本机已归档的 SEC 公开披露、已归档展品及最多一份此前财报/8-K相关披露。单文档最多 40,000 字符，总计最多 160,000 字符，明确标记截断；不是全长文本覆盖保证。
- 财报提取当前支持注册的数值型指标、指引范围及财报数据；自由文本语义与期间分类由用户复核。不自动处理所有公司特有指标或全部事件族。
- 解释只发送选定研究事实、计算和行情摘要，不发送持仓、账户余额、订单或凭证。合成数据带 `is_demo` 标识。
- 原文按不可信数据处理，模型不能使用工具、访问文中链接或改变账户状态。模型输出单独存储，不把其自称“已核实”视为证据。
- 同一模型/任务/输入哈希复用缓存；默认每日最多 20 次请求，失败尝试也计数，无隐式付费重试。
- AI 关闭、缺 Key、超时、格式错误、输出截断均明确降级；既有事实和核心计算不变。人工导入与确定性研究在 AI Off 下可用。
- 原始 AI 产物在 `ai_artifacts` 不可变保存；人工修订稿在 `research_drafts`；批准后使用既有证据/事实验证入口，记录审计。

## 持续更新与提醒

```bash
.venv/bin/python -m usoe --port 8788 --poll-research 900
```

最小间隔 300 秒。该模式包含 SEC 更新，不与 `--poll-sec` 同时启动。自动 DeepSeek 提取还要求 AI Assist、有效 Key 及“自动提取”偏好全部开启，每轮最多 5 份；不会自动批准事实或下单。关闭服务/电脑休眠后轮询停止，当前不安装开机启动服务。

候选待复核、研究条件满足和更新失败以去重的本机研究提醒保存，可标记已读。未发送邮件、短信或桌面推送。个人关注变更不影响用户另行配置的独立数据同步进程。

## 新增 API

沿用本机会话、同源 Origin、CSRF 和 JSON 要求。

| API（`/api/v1` 前缀） | 用途 |
|---|---|
| GET `/research` | 共享研究视图，含 impacts、impact_history、disclosures、候选、偏好、提醒、新鲜度及上次运行 |
| POST `/research/preferences` | `families,watchlist_only,auto_extract,security_ids?`；null=全部有效注册证券，[]=不更新任何证券 |
| POST `/research/run` | 请求单次异步研究更新，返回 202 和任务状态，不执行交易 |
| POST `/research/ensure` | 按新鲜度启动更新；`force:true` 请求立即更新，任务共用且不并发重复启动 |
| GET `/research/freshness` | 当前更新状态、阶段及最近运行信息 |
| POST `/research/exhibits` | `filing_id`；补齐支持的 SEC 展品 |
| POST `/research/extract` | `filing_id`；DeepSeek 候选提取，不写入 canonical facts |
| POST `/research/drafts/{id}/approve` | `confirmed:true,candidate?`；人工复核后严格验证并纳入研究 |
| POST `/research/notices/read` | `id`；标记提醒已读 |
| GET `/ai/status` | 配置存在性/模型/最近请求状态，不返回 Key |
| POST `/opportunities/{id}/explain` | 单机会辅助解释，独立于核心输出 |

## 验证范围

早期测试使用合成披露与模拟响应；后续已验证真实 DeepSeek API 的合成输入调用，并在真实工作区归档 SEC 披露。连通性不代表全部真实披露提取准确。Massive 历史行情可访问，但最近交易日与最新报价受到套餐权限限制，见 [实际接口验证](MASSIVE-LIVE-VALIDATION.md)。真实提取语义质量、完整实时行情链路、历史预测效果与长期运行仍待验收。

接口参考：[DeepSeek 官方调用说明](https://api-docs.deepseek.com/guides/harness)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 打开即更新的真实看板

真实工作区启动时自动检查同步时间；打开、返回标签页或从休眠恢复后，页面每 15 秒检查一次更新任务。距上次成功运行超过 15 分钟时后台启动更新，多标签页共用一个任务。失败后至少等 60 秒再尝试。页面展示缓存期间明确标注更新中、失败或过期，最近完成时间不等于行情实时时点。

SEC 首次补抓最近 30 天（额外一天索引延迟重叠），以后按每只股票持久化游标补齐离线期间披露，并读取需要的历史 submissions 文件。每只股票单轮最多 50 份；积压和失败不会推进游标，后续继续。全部文件归档后才记录同步检查时间。公司身份、原文及审计记录仍需校验。

开启自动提取后，每轮最多处理 5 份 8-K、10-Q、10-K、6-K、20-F 财报/指引候选，先尝试归档 EX-99 附件。剩余候选分批续跑，仍受 DeepSeek 每日额度限制。候选显示证券、披露时间、可核对数值的初步计算及缺失字段，AI 候选不会自动升格为已确认事实。需核对原文后纳入正式研究；人民币金额不得作为美元金额使用。

真实工作区的今日概览只显示仍有效的偏多与偏空摘要；披露原文与待复核事实集中在研究动态，完整判断在机会研究。没有 Massive Key 时会明确显示价格条件无法判断；接通后按订阅权限更新已确认机会行情。行情不完整、过期和失败均不能视为条件满足。工具不保证有机会，也不把已归档文件数量当作机会数量。

启动：`.venv/bin/python -m usoe --port 8788`。本地服务关闭或电脑关机时不会运行；重新启动后补齐。自动更新不依赖另建系统定时任务。


## 事件影响判断（第一阶段）

真实首页只展示偏多/偏空方向摘要，机会研究按偏多线索、偏空线索、分歧/证据不足组织完整判断，历史/失效判断默认收起。`event-impact-1` 是可解释的规则假设，不是经统计校准的收益预测。仅使用经过数字及期间校验的前后营收/EPS 指引、毛利率指引、营业利润率变化；不通过 AI 事件描述关键词推断方向，单期自由现金流也不能推断股价涨跌。校验失败时方向为 UNKNOWN，同时保留缺失原因。

AI 候选保留 REVIEW_REQUIRED，事实核对后才能成为正式研究；判断模块不执行交易、不自动批准事实。规则数值变化不是预测涨幅，公司前后指引不是市场一致预期。概率和预期收益字段均为 null。

每份判断展示原文入口、方向依据、缺少的一致预期、行情和证据条件，及 1/5/20 个 XNYS 交易日观察窗口。窗口从事件后首个收盘计数，是观察期限而非收益兑现承诺。20 个交易日窗口结束后归入历史；已有失效状态优先展示为失效。行情不完整、非 realtime 或超过 300 秒时不推断消息定价程度。已有涨幅仅作为已发生的观测，不转换成目标收益。

研究更新时追加记录 `impact_judgments`；同一判断状态不重复写入，变化后追加版本，A→B→A 也保留三次记录。数据库触发器禁止更新和删除。首次启用可通过 `Research.record_impacts()` 对现有证据记录当前判断；不会回填成事件发生时的预测。GET 看板接口不写历史。尚未接入收益回填与准确率统计，不能把这些记录视为经过验证的预测模型。

## 研究入口与用户流程（2026-10-03 更新）

三个页面是同一研究流程的不同入口，共用 `/api/v1/research` 数据；展示摘要、复核事实或完整判断不会创建第二份研究记录。

| 入口 | 核心问题 | 展示内容 |
|---|---|---|
| 今日概览 `#today` | 现在有哪些线索和待办值得看？ | 偏多/偏空总数、每类最近最多三条活动判断摘要、待复核事实和未读提醒数量；点击“查看完整判断”定位到对应事件 |
| 研究动态 `#research`（原每日研究） | 最近新增了什么证据，需要核对什么？ | 已归档 SEC 披露、候选事实复核、最近判断记录、本机提醒；关注设置与判断记录默认收起 |
| 机会研究 `#opportunities` | 这条逻辑为什么成立，现在还成立吗？ | 全部活动判断的方向依据、市场反应、1/5/20 交易日窗口、失效条件、缺失条件及下一步；历史/失效判断默认收起 |

建议流程：打开今日概览检查同步状态 → 挑选线索进入完整判断 → 在研究动态核对原文与候选事实 → 纳入正式研究并补齐行情 → 后续查看新证据、判断记录和失效条件。隔几天打开时，应检查同步是否完成，再在研究动态查看离线期间归档的披露。当前不是“上次访问以来”的专用差异报告；页面显示最近归档记录，不声称完整覆盖全部事件。

演示工作区仍使用合成数据，今日概览保留演示摘要，机会研究保留事件筛选和导出；不能把演示界面中的机会当作真实机会。

## 方向颜色与买入前核对

| 颜色 / 符号 | 含义 |
|---|---|
| 红色 ↗ | 偏多判断或偏多待复核线索 |
| 绿色 ↘ | 偏空判断或偏空待复核线索 |
| 黄色 ◇ | 多空分歧 |
| 灰色 | 证据不足、观察期结束或判断已失效 |

卡片保留方向文字与复核状态，不依赖颜色单独传递信息。历史和已失效卡片覆盖为灰色，保留原判断文字供复盘。未复核线索不等于已核实机会；红色也不等于买入触发。

买入前至少需要核对：原文及指标口径是否正确、行情时点和覆盖是否满足要求、价格是否已反映事件、判断失效条件，以及自身仓位和风险预算。当前提供研究筛选与跟踪，不提供经过历史校准的涨幅、胜率或自动购买决定。IBKR 不是无账户研究的必需配置，真实交易仍关闭。

## 本轮界面验证

已通过 JavaScript 语法和 diff 空白检查，并在浏览器确认：概览展示摘要及研究待办；摘要跳转至同一事件的完整判断；机会研究展示完整依据；研究动态不重复显示方向卡片，保留事实核对按钮。该验证只确认页面行为，不证明事件预测效果或数据源权限已补齐。

## 渐进展示

首页与机会研究卡片默认展示证券/方向、复核状态、披露时间、简短披露摘要、一项主要判断依据与下一步。长摘要限制为两行；首页点击“深入研究”进入同一判断，机会研究点击“展开依据、行情与风险”可查看完整摘要、全部依据、行情、观察期限、失效条件及原文/事实核对入口。研究动态的候选数值与校验结果同样默认收起。未复核摘要明确标注待核对；界面精简不改变事实、计算或方向规则，不把信息不足的事件强行标成看涨/看跌。

## 首页筛选与添加股票

首页只显示未失效且仍在观察期内的 BULLISH（红色）、BEARISH（绿色）线索，保留事实复核状态。黄色分歧、灰色证据不足或历史失效卡片及其统计不出现在首页；可在研究动态的“分歧、证据不足与历史判断”中展开查看。无有效红绿判断时显示“暂无明确方向线索”，不会填充其他方向。机会研究仍可查看完整判断。

首页及观察列表提供“添加股票”。填写股票代码、10 位 SEC CIK、公司名称和板块，提交“添加并关注”；添加成功后请求后台更新披露。当前公司信息需要用户填写，SEC 同步会核对 ticker/CIK 身份，核验失败不编造披露或机会。也可在设置页使用同一注册表单。此功能扩展个人关注范围，不是全市场扫描。

新股票自动加入 USER_WATCHLIST；如果研究偏好显式选择了股票，则在同一事务中追加新股票，保留既有股票和其他偏好。如果研究偏好为全部股票，则维持全部模式；重复注册不会重新启用已暂停股票。观察列表展示已注册公司及关注/暂停状态，暂停和恢复通过研究动态的关注设置调整。注册不会增加 DeepSeek 每日额度；股票变多后可能分轮处理新披露。
