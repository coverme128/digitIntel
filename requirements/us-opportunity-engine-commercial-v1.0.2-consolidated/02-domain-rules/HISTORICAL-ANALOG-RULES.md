# Historical Analog Rules

## 1. Analog Purpose

Historical analog 只提供上下文，不产生“未来必涨”结论。

## 2. Matching Dimensions

按优先级：
1. same event family
2. same company when sample sufficient
3. same sector / industry
4. similar magnitude bucket
5. similar pre-event trend
6. similar reaction bucket
7. similar market regime

## 3. Minimum Sample

- n < 10：只展示个案，不展示统计结论
- 10 <= n < 30：LOW_SAMPLE
- n >= 30：可展示 median / distribution

## 4. Outcomes

默认计算：
- 1D
- 5D
- 10D
- 20D

同时保存：
- max favorable excursion
- max adverse excursion
- excess return vs benchmark

## 5. Anti-Leakage

历史回放必须使用当时可获得的数据。
禁止：
- 使用未来 restatement
- 使用未来 index membership
- 使用事件后才知道的字段做事件前筛选
