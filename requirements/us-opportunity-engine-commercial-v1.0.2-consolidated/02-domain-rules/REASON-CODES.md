# Reason Codes

Reason Code 必须是稳定机器码。UI 可以翻译，代码不可随意改名。

## Evidence

- `EVIDENCE_OFFICIAL_CONFIRMED`
- `EVIDENCE_SUPPLEMENTAL_CONFIRMED`
- `EVIDENCE_MISSING`
- `EVIDENCE_CONTRADICTED`
- `EVIDENCE_REVIEW_REQUIRED`

## Data Quality

- `DATA_COMPLETE`
- `DATA_PERIOD_MISMATCH`
- `DATA_UNIT_MISMATCH`
- `DATA_STALE`
- `DATA_MARKET_WINDOW_INCOMPLETE`
- `DATA_BROKER_STALE`

## Materiality

- `MATERIAL_EARNINGS_INFLECTION`
- `MATERIAL_BUYBACK`
- `MATERIAL_INSIDER_BUY`
- `MATERIAL_ACTIVIST_EVENT`
- `MATERIAL_FINANCING`
- `MATERIAL_CORPORATE_EVENT`
- `MATERIAL_MNA_EVENT`

- `USER_WATCH`
- `USER_IGNORE`
- `USER_ENTER_CONFIRMED`
- `USER_EXIT_CONFIRMED`

## Rule

任何状态变化必须至少关联一个 reason_code。
不得仅保存自由文本原因。
