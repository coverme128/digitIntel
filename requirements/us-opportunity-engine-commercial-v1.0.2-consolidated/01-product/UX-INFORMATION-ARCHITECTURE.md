# UX / Information Architecture

## 导航

1. Today
2. Opportunities
3. Watchlist
4. Portfolio
5. History
6. Settings

不设置：
- News
- Social Feed
- AI Chat 作为首页
- Technical Indicator Dashboard

## Opportunity Card 最小信息

- Symbol / Company
- Event type
- Event timestamp
- Material change
- Price reaction
- State
- One-line reason
- Next trigger

## Detail 信息优先级

P0：
- What changed
- Why material
- Reaction
- State
- Trigger
- Invalidation

P1：
- Fundamental deltas
- Sector context
- Historical analogs
- Evidence

P2：
- AI explanation
- Raw filing navigation

## UI 禁止项

- 用红绿大按钮直接显示“买/卖”
- 把 AI confidence 当投资胜率
- 用 0–100 总分隐藏底层原因
- 无证据显示具体数字
- 无法解释的 signal badge
