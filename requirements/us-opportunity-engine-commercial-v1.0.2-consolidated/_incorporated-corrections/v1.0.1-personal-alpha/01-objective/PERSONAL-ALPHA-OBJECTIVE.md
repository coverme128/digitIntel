# Personal Alpha Objective

## 1. 最终目标

US Opportunity Engine 首先服务个人账户。

正式目标不是“信息更多”“机会更多”或“每天有交易”，而是：

> 发现少量高质量、可验证、可执行的机会，并通过更好的筛选、入场、风险控制和退出，提高长期风险调整后收益。

## 2. 三层目标

### Layer A — Opportunity Discovery

系统必须提高：
- Material event coverage
- High-quality opportunity recall
- Noise rejection
- Evidence quality

但禁止以“机会数量”作为成功指标。

### Layer B — Decision & Execution Quality

系统必须提高：
- WATCH → READY 的有效性
- READY → ENTER 的纪律性
- Entry quality
- Invalidation discipline
- Avoided bad trades
- Portfolio-fit quality

### Layer C — Long-term Outcome

最终评估：
- Net P&L
- Expectancy per trade
- Max Drawdown
- Profit Factor
- Risk-adjusted return
- MFE / MAE
- Rule-family performance
- Avoided-loss contribution

## 3. 优先级

发生冲突时：

`Capital Preservation > Positive Expectancy > Opportunity Count > UI Activity`

系统允许：
- 0 Opportunity
- 0 Entry
- 多日不交易

系统禁止：
- 为保持活跃而制造机会
- 因短期 P&L 自动放宽规则
- AI 自动修改核心规则
- 追求高胜率而忽略盈亏比
