# US Opportunity Engine — Personal Alpha Rule & Golden Closure v1.0.1

这是 `US Opportunity Engine Commercial V1.0` 的增量 Closure Pack。

它不重做产品架构，不新增产品模块，只补齐真正决定“能否用于个人真实交易”的四层：

1. Personal Alpha Objective
2. Exact Opportunity / Entry / Invalidation Rules
3. Portfolio Risk Parameters
4. Golden / Shadow / Paper / Live Validation Contract

## 冻结目标

不是“发现更多机会”。

不是“最大化短期 P&L”。

正式目标为：

> 发现少量高质量、可验证、可执行的美股机会，并通过纪律化筛选、入场、风险控制、持仓管理和退出，提高长期风险调整后收益。

链路：

`DISCOVER → QUALIFY → WATCH → READY → ENTER → MANAGE → EXIT → LEARN`

## 与 v1.0 的关系

优先级：
`v1.0 MASTER > v1.0.1 Closure > v1.0 implementation details`

v1.0.1 只覆盖以下内容：
- Personal Alpha Objective
- Opportunity rule thresholds
- Entry / invalidation family rules
- Portfolio risk defaults
- Outcome metrics
- Validation and learning loop

其余 v1.0 Frozen Items 保持不变。
