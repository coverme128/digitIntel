# Portfolio Risk Parameters — Personal Baseline

These are conservative initial defaults for validation, not universal investment advice.

## 1. Per-trade planned loss

Default max planned loss:
- 0.50% of account equity

Hard cap baseline:
- 1.00% of account equity

## 2. Position concentration

Default warning:
- >10% of equity in one stock

Default hard block:
- >15% post-entry single-name exposure

## 3. Sector exposure

Warning:
- >30%

Hard block:
- >40%

## 4. Catalyst concentration

Same catalyst/factor cluster warning:
- >25%

Hard block:
- >35%

## 5. Open risk

Sum of planned stop-loss risk:

Warning:
- >3% equity

Hard block:
- >5% equity

## 6. Cash / Buying Power

Hard block when:
- broker data stale
- buying power unknown
- reconciliation mismatch
- duplicate order uncertainty

## 7. Risk/Reward Worksheet

Before ENTER save:
- intended entry
- invalidation
- per-share risk
- target/management hypothesis
- planned capital
- planned max loss

No automatic position size from AI.
